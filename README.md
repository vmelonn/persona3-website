# Persona 3 Website

https://vmelonn.github.io/persona3-website/

A personal portfolio website styled after Persona 3's UI aesthetic. Built with React, Vite, and Framer Motion.

## Pages

- `/` — Main menu with looping background video
- `/about` — About me
- `/resume` — Resume
- `/socials` — Social links

## Stack

- React 19 + React Router 7
- Framer Motion (page transitions)
- Vite 8
- Deployed via `gh-pages`

## Setup

```bash
npm install
npm run dev       # dev server
npm run build     # production build
npm run deploy    # deploy to GitHub Pages
```
